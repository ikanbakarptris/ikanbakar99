# Agung Bike Connect

INTENT: Build a mobile-first, high-converting landing page for a local bicycle repair shop named "Agung Bike Repair".

SCOPE:

- Hero Section: Use the PAS (Problem, Agitation, Solution) formula tailored for cyclists needing reliable repairs.

- Services Section: List services like "Servis ringan", "Setel velg/jari-jari", "Upgrade & Restorasi", and "Perakitan".

- Trust Signals Section: Display a 5.0 rating badge (130 reviews), a customer photo gallery, and highlight the "Pickup and Drop-off" service.

- Floating/Sticky CTA: A sticky action bar at the bottom of the screen exclusively for mobile views.

UI/UX:

- Enforce strict Mobile-First UX (Thumb Zone) principles.

- Primary CTA: "Konsultasi Servis via WhatsApp" linking directly to wa.me/62895382966573.

- Secondary CTA: "Petunjuk Arah ke Bengkel" linking to Google Maps.

- Place real workshop photos and client testimonials immediately following the Hero section to build trust.

DATA STATE:

- Use static mock data for this v1 build (Frontend-first approach). Do not implement database schemas or login flows yet.

ACCEPTANCE CRITERIA:

- The layout is fully responsive and highly optimized for mobile loading speed.

- The sticky CTA remains permanently visible at the bottom of the screen on mobile devices.

- The UI uses semantic HTML and clean Tailwind styling, ready for future CMS integration.
